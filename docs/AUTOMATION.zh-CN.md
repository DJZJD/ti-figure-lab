# TiFigure Lab 当前功能说明

这是一个本地运行、英文界面的论文数据提取与审核工具。目标流程是：导入 PDF → 请求外接模型提取或选择测量对象 → 本地工具计算 → 人工审核 → 导出带证据的数据。当前版本属于实验预览版，尚不适合无人审核地生成科研训练集。

## 目前能做什么

| 功能 | 当前能力 | 需要人工处理的部分 |
| --- | --- | --- |
| PDF 导入 | 保存原始 PDF，提取原生文字，生成页图和请求材料 | 扫描件、复杂排版或缺失信息可能无法处理 |
| 作者报告值 | 调用 DeepSeek，提取规定范围内的数值、单位、样品条件和引用证据 | 核对原文、统计含义、试验条件和样品归属 |
| 带数据点的坐标图 | 模型选图、定位子图、识别刻度和点符号；本地换算坐标 | 自动分支限无断轴的线性坐标；需检查标定、符号中心和图例 |
| XRD 峰位 | 本地生成峰候选，模型对候选进行保留、拒绝或存疑判断；提供辅助取点 | 叠线、细小峰、文字遮挡可能识别错误；不能直接当成定量相分析 |
| 灰度显微图 | 模型提出测量区域和比例尺，本地灰度区域工具尝试生成轮廓，计算面积和等效圆直径 | 轮廓可能泄漏、碎裂或选错对象；相身份需核实，低分辨率无法补回真实细节 |
| 手工修正 | 标定比例尺或坐标轴，编辑点、线和多边形；保存工作台 | 自动结果失败时可人工重新标定和测量 |
| 字段对齐 | 导入参考 master，查看目标字段，准备待审测量草稿及部分映射建议 | 不同论文的样品代码不通用；单颗粒面积不能直接当成总体平均粒径 |
| 数据导出 | CSV、工作台 JSON、论文任务归档，以及明确审核后生成的 TiFM master 副本 | 当前副本适配器只替换已有合格数值字段，不自动新建完整 master |

## 自动化怎样运行

1. 在 **API settings** 配置接口。当前直接联网流程使用 DeepSeek；另有离线、提供商中立的 JSON 交换接口，不等于已实现所有厂商的一键切换。
2. 打开 **Paper extraction**，导入论文，填写论文标签。导入本身不调用付费模型。
3. 选择作者报告值、带点符号的坐标图、XRD 或显微图分支，说明目标。图像任务先从论文文字选图，再发送相关页图或裁图，通常不发送所有页图。
4. 每次模型调用都会带上对应的 Markdown 规则。规则来自 `configs/`，任务保留其快照。模型提出结构化结果或工具参数，本地程序执行受支持的计算，不通过模拟鼠标操作 ImageJ/GetData。
5. 检查原文、裁图、标定点、候选点或轮廓及警告。接受、拒绝或修正后保存。自动结果默认待审，数值接近参考值不代表自动通过。
6. 将确认后的结果映射到正确样品和字段，再导出。需要保存全过程时下载任务归档；未保存的界面编辑不算归档内容。

## 当前没有完成的功能

- 自动检索、下载大量符合条件的论文，以及从出版社网站获取更高清原图。
- 通用 OCR、任意连续函数曲线追踪、自动处理所有断轴或多坐标轴图。
- 可靠的 α/β 相、初生/次生相自动鉴定和经过领域训练的显微分割模型。
- 通过用户审核自动微调模型；当前反馈用于保存修订和证据，不自动训练。
- 无人审核的百篇级准确率保证，以及下游训练程序的完整兼容性认证。

## 数据、接口与导出边界

程序运行在本机 `127.0.0.1`，不是公共托管网站。显式发起模型请求时，相关论文内容会发送至所选接口。API Key 保存在服务器会话内存中，服务重启后需重新配置。

工作数据与源码包分开存放。任务归档可包含原论文、模型输入输出、裁图和审核记录，应自行保管，不作为公开源码上传。master 副本导出包含原参考数据、采纳记录和待审附件，但不嵌入全部原始图像；它也不是工作台备份恢复格式。

公开源码含程序、规则文档、虚构教学样例和软件测试代码，不包含私人论文、运行历史、API Key 或科研结果库。软件测试通过只能说明被覆盖的行为符合预期，不能证明对未知论文的识别准确率。

## 从哪里开始试用

安装和启动命令见仓库 `README.md`。无 API Key 时先按 `DEMO.md` 练习合成图的标定、测量、保存和导出；有接口后再导入一篇论文，先做一个目标图或一类报告值，并逐条核对。
